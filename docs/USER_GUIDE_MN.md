# PlateWatch — Автомашины дугаар танигч

Дан Python desktop програм: **Tkinter + Ultralytics YOLO + Кирилл PP-OCRv5 + EasyOCR (mn, en) + OpenCV**.
Зураг, видео болон USB/webcam камераас Монголын түгээмэл **4 цифр + 3 кирилл үсэг** бүхий дугаар уншина.
Өгөгдөл нь CSV, JSON, JPEG файлд хадгалагдана. Вэб frontend/backend, SQL болон сервер суулгах шаардлагагүй.

## Шууд ажиллуулах

Камераа шууд асаах бол **`camera.bat`**-ийг давхар товшино. Камерыг автоматаар олно; ажиллахгүй хуучин индекс сонгогдсон байсан ч байгаа төхөөрөмж рүү шилжинэ.
Одоогийн Python хувилбар **2.8.1**. Хазайсан хоёр мөртэй дугаарын бодит тоо, үсгийн мөрийг олж, бамперын илүү хэсгийг оруулахгүйгээр тус тусад нь тэгшлэн уншина. YOLO хүрээ олоогүй үед том оролт болон цагаан хавтангийн хэлбэрээр нэмэлт хайлт хийнэ. Видео дахь дугаарыг хөрш кадруудаар баталгаажуулж хадгална. Таних горим, кадрын зай, дүрсний хурд нь **Тохиргоо → Видео ба таних хурд** хэсэгт байрлана.

Шинэчлэлтийн дараа өмнөх PlateWatch цонхоо хааж, энэ хавтасны PowerShell-д **`.\run.bat`** ажиллуулна. Цонхны гарчигт **2.8.1** гарсан эсэхийг шалгана.

1. Энэ хавтас дахь **`run.bat`** файлыг давхар товшино. VS Code нээх шаардлагагүй.
2. **Зураг импортлох**, **Видео импортлох**, эсвэл камерын индексээ сонгоод **Камер** дээр дарна.
3. Дугаар танигдмагц баруун самбарт дугаар, OCR/YOLO итгэлцүүр, хязгаарлалтын төлөв гарна.
4. Бүртгэл дээр давхар товшиж бүтэн зураг, дугаарын хэсэг, JSON мэдээллийг нээнэ.

Windows 10/11, 64-bit **Python 3.11–3.13** хэрэгтэй. Python 3.15 сонгохгүй.
Анхны эхлэлт `.venv` үүсгэн шаардлагатай сангууд суулгана. Бэлэн сан байвал дахин суулгахгүй.
Шинэ компьютер дээр сан, YOLO болон OCR жин татахад интернэт, хэдэн минут болон ойролцоогоор 1–2 GB сул зай шаардагдаж болно.
Жин татагдсаны дараа танилт **локал**, интернэтгүй ажиллана. Зураг/бичлэгийг серверт илгээхгүй.

Камерын сонголтыг **Авто** дээр тавиад **Камер** дарна. Илэрсэн бодит төхөөрөмжийн индексийг програм өөрөө харуулна.
Камер огт олдохгүй бол Windows Settings → Privacy & security → Camera → desktop apps тохиргоог шалгаж, камер ашиглаж буй бусад програмыг хаана.

## Видео шалгах, дүрс томруулах

### Бүдэг бичлэгийг зогсоож таних

1. **+ Видео** товчоор бичлэгээ оруулж, автомашины дугаар хамгийн ойр, тод харагдах үед **Дүрс зогсоох** дарна. Видео зогссон ч арын AI шалгалт үргэлжилнэ.
2. **Энэ кадрыг таних** дарна. Эх кадрын пикселээс дугаарын хэсгийг ялгаж, томруулах, гэрэл/тодрол тохируулах, үсэг-тоог тусад нь унших аргуудыг шалгана.
3. Бүдэг кадр бүрэн уншигдахгүй бол ойролцоох бодит кадруудаас ижил дугаар давтан уншигдах эсэхийг харьцуулна. Баталгаажсан өөр кадр сонгогдвол **Ойролцоох баталгаажсан кадр** гэсэн тайлбар, тухайн кадрын хугацаа гарна. Хадгалсан хүрээ, зураг, хугацаа нь уншсан бодит кадрынх байна.
4. Дугаар баруун талд томоор, доор нь тайрсан хэсэг гарна. **Энэ шалгалтын дугаарууд** жагсаалтад танигдсан бүх ялгаатай дугаар нэмэгдэнэ.

Бичлэгийг шалгахдаа **Видеог шалгах** дарна. Эхнээс нь тохируулсан кадрын зайгаар шалгана; дүрс AI-ийн шалгасан кадраар шинэчлэгдэж, явц доод зурваст гарна. **■** нь бүх шалгалт, зогсоосон кадрын ажлыг цуцална.

- **Тохиргоо → Видео ба таних хурд → Таних горим**: Хурдан / Тэнцвэртэй / Нарийвчилсан горимоос сонгоно. Эхлээд Тэнцвэртэй горим ашиглана; Нарийвчилсан нь илүү олон хувилбарыг харьцуулдаг тул удаан байж болно. Нарийвчилсан уншилтад дор хаяж хоёр хувилбар давхцаж, зөрүүтэй уншилтуудаас давамгайлсан байх шаардлагатай.
- **Хэдэн кадр тутамд шалгах** (дээрх тохиргоонд): 1 бол бүх кадр; 10 бол 30 FPS видеонд ойролцоогоор 0.33 секунд тутам; 30 бол секунд тутам. Их утга хурдан боловч хурдан өнгөрсөн машин алгасаж болно. Шинэ тохиргооны анхны утга 10; өмнө хадгалсан кадрын зай хэвээр ачаалагдана.
- **Тохиргоо → Дугаарыг ойр кадраар батлах**: танигдаж эхэлсэн дугаарыг алдахгүйн тулд ойролцоогоор 0.1 секундийн зайгаар нэмж шалгана. Баталгаажмагц ердийн кадрын зай руу буцна. Унтраавал яг тохируулсан зайгаар шалгана. Нарийвчилсан горимд жижиг дугаарыг том хэмжээ болон хэсэгчилсэн илрүүлэлтээр дахин хайдаг тул удаан байж болно.
- **Дүрсний хурд**: 0.25–4 дахин тоглуулна. AI шалгах кадрын зайг тусад нь тохируулна.
- **Хэрэглэх** (Тохиргоо дотор): дээрх гурван утгыг хадгалж, ажиллаж буй видеоны дараагийн кадраас хэрэглэнэ. AI загварыг дахин ачаалахгүй.
- **Тохиргоо → Видео/камерын OCR доод босго**, **батлах кадр**: итгэл сул, зөрүүтэй уншилтыг шүүнэ. Ижил машины уншилтуудын жингийн 70%-аас доош дэмжлэгтэй хувилбарыг харуулахгүй, хадгалахгүй. Батлах кадрыг 1 болговол давтан баталгаажуулалт сулрана.
- **Тохиргоо → Зогсоосон кадрын нэмэлт хайлт**: 0 бол зөвхөн сонгосон кадр; 2 бол дараагийн хоёр бодит кадрт хүртэл хайна. Энэ утгыг багасгахад гараар шалгах хүлээлт буурна.

**Энэ кадрыг таних** нь видео дахь машин бүрийг хөрш кадруудаар баталгаажуулна. Дэлгэцэд баталгаажсан болон бүрэн тодроогүй дугаарын тоог тусад нь харуулна. Хоёр OCR өөр үсэг уншвал өндөр хувийн оноог нь шууд зөв гэж сонгохгүй.

Алдагдсан үсэг, тоог хиймлээр нөхөж таахгүй. Эх файлд мэдээлэл нь алга болсон бол томруулалт бүрэн сэргээхгүй; боломжтой үед илүү өндөр нягтралтай эх бичлэг ашиглана.

- **+ Видео шалгах** эсвэл дүрсний дээрх **+ Видео** товчоор MP4, AVI, MOV, MKV, WEBM, WMV, M4V сонгоно. JPG/PNG нь видео биш тул **+ Зураг** товчоор оруулна.
- Бичлэг шууд тоглоно. Доод талд тоглож буй хугацаа, AI-ийн шалгаж буй хугацаа тусдаа гарна. Бичлэг дууссан ч AI шалгалт үргэлжилж болно; доод явцын зурвас дүүрч, **Дууслаа** гэж гарахыг хүлээнэ.
- **Ⅱ Дүрс зогсоох** нь видеоны харагдацыг царцаана; AI шалгалт үргэлжилнэ. **↻** нь сонгосон видеог эхнээс нь дахин тоглуулж шалгана.
- **F11**, **⛶** товч эсвэл дүрсэн дээр хоёр дарахад бүтэн дэлгэцээр харуулна. **Esc** нь бүтэн дэлгэцээс буцна; энгийн горимд Esc нь ажлыг зогсооно.
- **Бүтнээр** нь дүрсийг харьцааг нь хадгалж, талбайдаа хамгийн томоор багтаана. Товчийг дахин дарж **Дүүргэх** горим сонговол талбайг дүүргэж, илүү гарсан захыг төвөөс нь тайрч харуулна. Эх файлыг өөрчлөхгүй.
- Хажуу тийш эргэсэн бичлэгт **↶ 90°** дарна. Дүрс болон AI шалгалтыг хамтад нь эргүүлж эхнээс нь шалгана. Өөр файл оруулахад эргэлт тэглэгдэнэ.
- Хяналтын дэлгэцээс давхар түүхийн хүснэгтийг авч, дүрсэд илүү зай гаргасан. Бүх бүртгэл **Илрэлтийн түүх** цэсэнд хэвээр байна.

Терминалаас видеог шууд нээх:

```powershell
.\run.bat --video "C:\Videos\test.mp4"
```

Хажуу тийш эргэсэн видеог зүүн тийш 90° эргүүлж нээх:

```powershell
.\run.bat --video "C:\Videos\test.mp4" --rotate 270
```

## Боломжууд

- Зураг сонгомогц, камер нээгдмэгц дүрс шууд гарна; AI ачаалж дуустал хар дэлгэц хүлээхгүй.
- Камер ажиллаж байхад зураг/видео сонговол өмнөх ажлыг зогсоож автоматаар шилжинэ.
- Файл сонгох цонхоос гадна зүүн талын замын талбарт файлын бүтэн замыг хуулж **Нээх** дарж болно.
- Нэг төслөөс давхар GUI нээж камерыг булаалдахгүй; дахин ажиллуулбал нээлттэй цонхоо гаргана.
- Нэг болон олон зураг импортлох, MP4/AVI/MOV/MKV видео нээх.
- Камерын дүрсийг тусдаа thread-ээр авч, GUI гацаахгүйгээр AI танилт хийх.
- Видео/камерын дугаарыг анхдагчаар **2 удаагийн уншилтаар баталгаажуулах**.
- Ижил дугаарыг анхдагчаар **20 секунд** тутмаас ойр давтаж хадгалахгүй; зураг бүр тусдаа хадгалагдана.
- Бүтэн кадрт хүрээ, кирилл дугаар зурах; дугаарын crop, цагтай JSON, CSV бүртгэл хадгалах.
- Түр зогсоох, үргэлжлүүлэх, бүрэн зогсоох, гараар кадр хадгалах.
- Хүсвэл боловсруулсан видеог MP4 болгон хадгалах.
- Дугаар, огноо, хязгаарлалтын төлвөөр хайх; Excel-д нээгдэх UTF-8 CSV экспортлох.
- Өнөөдрийн нийт илрэлт, ялгаатай дугаар, хуваариар хязгаарлалттай илрэлтийн тоо.
- Үндсэн өнгийг цэнхэр, ногоон, нил ягаан, ягаан болгох; OCR/YOLO босго, видео кадрын алхам, давталтын зайг өөрчлөх.
- `Ctrl+O`: зураг импортлох; `Ctrl+S`: кадр хадгалах; `Esc`: зогсоох.

## Хадгалалтын бүтэц

```text
data/
  settings.json              # GUI тохиргоо
  detections.csv             # Дугаар, цаг, эх үүсвэр, итгэлцүүр, хуваарь, зургийн зам
  app.log                    # Алдааны дэлгэрэнгүй
  evidence/YYYY-MM-DD/
    ..._1234УБА.jpg           # Хүрээ, дугаартай бүтэн кадр
    ..._1234УБА_plate.jpg     # Дугаарын хэсэг
    ..._1234УБА.json          # Бүртгэл, OCR raw text, bbox, хуваарийн үр дүн
  snapshots/                 # Гараар хадгалсан кадр
  videos/                    # Сонголтоор хадгалсан MP4
  models/ocr/                # EasyOCR-ийн татсан жин
  models/plate_detector.pt   # Анх хэрэглэхэд татах бэлэн YOLO detector
models/
  mongolian_best.pt          # Өөрийн өгөгдлөөр сургасны дараах жин
```

Цагийг компьютерын timezone-оос үл хамааран **Улаанбаатар UTC+08:00**-аар бүртгэнэ.
Видео дахь кадрын байрлалыг `video_seconds` баганад хадгална. Импортын `detected_at` нь боловсруулах үеийн цаг;
эх бичлэгийн бодит авсан огноо гэж үзэхгүй. JSON дахь `time_basis` үүнийг ялгана.
Хадгалалтын хавтсыг өөрчлөхөд `PLATEWATCH_DATA_DIR` environment variable ашиглаж болно.

## Тухайн өдөр зорчих эсэх

**Хязгаарлалт** цэсэнд `1113` шиг зөвхөн 4 цифр эсвэл `1113УБА` шиг бүтэн дугаар оруулж болно.
Гол үр дүнд хязгаарлах өдөр болон зорчих өдрүүд шууд гарна: анхдагч хуваариар **1113 → Лхагва**.
Огноо, цаг оруулаад **Явах өдрийг харуулах** дарвал сонгосон тухайн өдрийн төлөвийг тусдаа мөрөнд харуулна.
Жишээлбэл `2026-11-13` нь Баасан боловч 1113-ын хязгаарлах өдөр нь Лхагва хэвээр байна.
Сүүлийн цифрийг `1234УБА` дугаарын **4** гэсэн тооноос авна.

Анхдагч жишиг хуваарь: Даваа 1/6, Мягмар 2/7, Лхагва 3/8, Пүрэв 4/9, Баасан 5/0; 08:00–20:00.
Үүний суурь эх сурвалж нь [Тээврийн цагдаагийн албаны тайлбар](https://transportation.police.gov.mn/a/4646).
Энэ нь шинэ түр зохицуулалтыг автоматаар татах үйлчилгээ биш. Өдрийн бодит зохицуулалтад тааруулж **Тохиргоо** цэснээс:

- 7 хоногийн хуваарь, тэгш/сондгой, эсвэл унтраалттай горим сонгоно.
- Цагийн хүрээ, өдрүүдийн хязгаарлах цифр, тэгш огнооны дүрмийг тохируулна.
- Эх үүсвэр хязгаарлалтын бүсэд байгаа эсэхийг гараар тэмдэглэнэ.
- Баяр/чөлөөлөх өдрүүдийг `2026-11-26, 2026-12-29` хэлбэрээр нэмнэ.
- Чөлөөлөх дугаарыг `1234УБА, 5678УБВ` хэлбэрээр нэмнэ.

Төлөв бол **тохируулсан хуваарийн тооцоо**, албан ёсны зөрчил/торгуулийн шийдвэр биш.
Бүртгэлд илрээгүй нь машин тухайн өдөр огт яваагүй гэсэн баталгаа болохгүй.
Бодит байршил, нийтийн амралтын өдрүүд болон тусгай зөвшөөрлийг автоматаар тодорхойлохгүй.

## Монгол өгөгдлөөр fine-tune хийх

Оруулсан detector нь [Koushim-ийн YOLOv8n дугаар илрүүлэгч](https://huggingface.co/Koushim/yolov8-license-plate-detection).
Татахдаа тогтмол revision, SHA-256 шалгана. Монгол өгөгдлөөр сургасан, үнэлсэн гэж тооцохгүй.
EasyOCR-ийн [дэмждэг хэлний жагсаалтад](https://jaided.ai/easyocr/) Монгол `mn` багтдаг.
Кирилл уншилтад PaddlePaddle-ийн [cyrillic_PP-OCRv5_mobile_rec_onnx](https://huggingface.co/PaddlePaddle/cyrillic_PP-OCRv5_mobile_rec_onnx) загварыг CPU дээр ажиллуулна. Apache-2.0 лицензтэй, 8 MB жинг тогтмол revision болон SHA-256-аар шалгаж татна. Жин, цагаан толгойн файл `data/models/ocr/cyrillic_ppocr` дотор хадгалагдаж, дараа нь интернэтгүй ажиллана. `run.bat` шаардлагатай ONNX Runtime санг автоматаар шалгана.
Бодит танилт нь дугаарын хэмжээ, фокус, гэрэл, өнцөг болон Монгол өгөгдлийн чанараас хамаарна.
Тусгай/дипломат/мотоциклын өөр формат энэ хувилбарын 4+3 шалгалтаар бүртгэгдэхгүй.

1. [Roboflow Universe License Plate Recognition](https://universe.roboflow.com/roboflow-universe-projects/license-plate-recognition-rxg4e) өгөгдлийг **YOLO** форматаар экспортолно.
2. Монгол дугаарын өдөр/шөнө, өөр өөр өнцөг, цаг агаартай зураг нэмнэ. Label Studio эсвэл CVAT-д дугаарын хүрээг `license_plate` class-аар тэмдэглэнэ.
3. Бүх зураг дээр нэг class-ийн ID `0` ашиглана. Frame-ээр бус, нэг автомашин/бичлэгээр train/validation/test-ийг салгаж өгөгдөл давхцахаас сэргийлнэ.
4. Экспортын `data.yaml` замаа ашиглан дараах командыг ажиллуулна:

```bat
.venv\Scripts\python.exe -m tools.train --data datasets\mongolian_plates\data.yaml --epochs 80 --device cpu
```

CUDA суусан NVIDIA GPU-тэй бол `--device 0` хэрэглэж болно.
Сургасан жин `models/mongolian_best.pt` болно. **Тохиргоо → Өөрийн YOLO .pt → Сонгох → Тохиргоо хадгалах**.
Бэлэн жингийн сонголтод буцахдаа model замыг хоосолно.
Өгөгдлийн болон Ultralytics/EasyOCR/моделийн лиценз эх үүсвэртээ үйлчилнэ.

## EXE бүтээх

v2.2.0 нь зураг дээрх тасалдсан дугаарын хүрээг нөхөж унших, MNG/MGL тэмдгийг ялгах, 1113-ын гарагийг зөв тусад нь харуулах засваруудтай.
Бэлэн багцын эхлэх файл: `dist/PlateWatch/PlateWatch.exe`. Хувилбар нь тухайн хавтасны `VERSION.txt` болон цонхны гарчигт гарна.
Windows Application Control гарын үсэггүй EXE-г хориглосон тохиолдолд энэ компьютер дээр шалгаж ажиллуулсан **`run.bat`** хувилбарыг ашиглана.
Энэ хавтаст байгаа EXE нь өмнөх **2.2.0** хувилбар бөгөөд 2.8.1-ийн шинэчлэлтийг агуулаагүй. Түүнийг ажиллуулахад Windows `4551` хориг өгсөн тул frozen GUI/AI runtime энд шалгагдаагүй; дэлгэрэнгүй нь `test_artifacts/exe_verification_2_2.json`-д бий. Шинэ засварыг **үндсэн хавтасны `run.bat` эсвэл `camera.bat`**-аар ажиллуулна.
Системийн хамгаалалтын тохиргоог програм өөрчлөхгүй.

`build_exe.bat`-ийг давхар товшино. PyInstaller сууж, `dist/PlateWatch/PlateWatch.exe` үүснэ.
EXE-г дамжуулахдаа **`dist/PlateWatch` хавтсыг бүтнээр нь** хуулна; `_internal` болон `models` нь хамт байх ёстой.
OCR жинг урьдчилан **Тохиргоо → AI загвар бэлтгэх / шалгах** үйлдлээр татвал build дотор хуулна.
EXE build нь том хэмжээтэй; `.bat` ажиллахад EXE шаардлагагүй.

## Шалгах

**2.8.1**-д сүүлд мэдээлсэн босоо зургийн **7960 УЕХ** дугаарыг ердийн импорт болон **Энэ кадрыг таних** үйлдлээр зөв уншсан. Зөвхөн дугаарын хүрээ олох нь хангалтгүй байсан: бампер хамарсан тайралтын доторх хазайсан хоёр мөрийг ялгах хэсгийг нэмсэн. Дугаар бүрэн уншсан эх үр дүнг хоосон нэмэлт OCR дарж устгадаг нөхцөлийг мөн зассан.

**109 автомат тест** тэнцсэн. Бодит 9 зураг + үүсгэсэн 1 зургийн дугаарууд зөв, ном/өөр форматтай дугаарын 6 бодит зураг + үүсгэсэн 3 эсрэг жишээнд Монгол дугаар буруу бүртгээгүй. Шалгалт хүлээсэн бүх дугаарын яг ижил олонлогийг шаардана; илүү буруу дугаар гарвал унадаг. Бүтэн видео 3 дугаартайгаа, камер, түүх, CSV экспорт, тохиргоо хадгалалт болон `run.bat --smoke-test` тэнцсэн. [Тайлан](../test_artifacts/audit_2_8_1/final/report.json), [бодит дэлгэц](../test_artifacts/audit_2_8_1/final/reported_photo_gui.png).

```powershell
.\.venv\Scripts\python.exe -m tools.verify_project --manifest test_artifacts/audit_2_8_1/cases.json --output test_artifacts/audit_2_8_1/recheck
```

`--mode detailed` нэмбэл Нарийвчилсан горимоор шалгана. Эдгээр зурагт тэнцсэн нь бүх бүдэг, халхлагдсан дугаар зөв уншигдана гэсэн баталгаа биш; дэмжих үндсэн формат нь **4 цифр + 3 кирилл үсэг** хэвээр.

2026-11-17-ны **2.8.0** шалгалтаар **103 автомат тест** тэнцсэн. Хэрэглэгчийн 8 бодит зураг болон 1 үүсгэсэн зураг бүгд хүлээсэн бүтэн дугаараа уншиж, зураг/тайралт/JSON/CSV хадгалсан. Өмнө нь огт илрээгүй **1742 УБР**, алдсан **8804 ДОУ**, буруу уншсан **7319 ДАР** энэ шалгалтад зөв болсон. Дугааргүй 3 зурагт дугаар бүртгээгүй.

Бодит бичлэгийн 64 шалгасан кадраас **7034 УБУ**, **6657 УНА**, **4000 УЕО** бүртгэгдсэн. Камерын 3 бодит AI шалгалт, төхөөрөмж суллаад дахин нээх, түүхийн хайлт, шүүсэн CSV экспорт, хязгаарлалтын хуваарь, тохиргоо хадгалах/дахин унших үйлдлүүд тэнцсэн. `run.bat --smoke-test` амжилттай асаж хаагдсан. Дэлгэрэнгүй: [VALIDATION.md](VALIDATION.md), нотолгоо: [test_artifacts/audit_2_8/final/report.json](../test_artifacts/audit_2_8/final/report.json).

Шинэ код дээр зураг, GUI, дугааргүй зургийн шалгалтыг дахин ажиллуулах:

```powershell
.\.venv\Scripts\python.exe -m tools.verify_project --manifest test_artifacts/audit_2_8/cases.json --output test_artifacts/audit_2_8/recheck
```

Manifest доторх эх зургийн замууд энэ компьютерийн файлуудыг заана; өөр компьютер дээр өөрийн зураг ба зөв дугаараар шинэчилнэ. `--camera` нэмбэл бодит камер шалгана. `--video` нь өмнө шалгасан 12.23 секундийн эх бичлэгийн гурван дугаарыг шалгах зориулалттай. Эдгээр нь алдааг дахин гаргах шалгалт; бүх замын нөхцөлийн нарийвчлалын хэмжилт биш. Бичлэгийн жижиг пикапын үсэг бүрэн батлагдаагүй хэвээр.

v2.7.0-д алдаа гарсан эх кадрыг хөрш кадруудаар шалгаж **6657УНА** гэж баталгаажуулсан. Бүтэн бичлэгийн шалгалтад **7034УБУ**, **6657УНА**, хоёр мөртэй **4000УЕО** гурвуулаа бүртгэгдсэн; өмнөх **6657УНХ/6657УНЬ** хувилбар хадгалагдаагүй. Тэнцвэртэй горимд 64 кадр, загвар ачаалалтайгаа 48.58 секунд зарцуулсан. Хажуугийн пикапын жижиг үсэг баталгаажуулах босгонд хүрээгүй тул тодроогүй гэж үлдэнэ. Тайлан, дэлгэцийн зураг: `test_artifacts/accuracy_2_7/`.

v2.6.0-ийн **74 автомат тест** тэнцсэн. Алдаа гарсан бодит 12.23 секундийн бичлэгийг 10 кадр тутамд шалгахад 37 кадр, загвар ачаалалтайгаа **29.3 секунд** зарцуулж, **7034УБУ** дугаарыг хадгалсан. `1034УБУ`, `1703УБУ`, `1032УБУ` гэсэн зөрүүтэй хувилбарууд энэ шалгалтад хадгалагдаагүй. Тайлан, дэлгэцийн зураг: `test_artifacts/accuracy_speed_2_6/`. Энэ нь тухайн алдааны шалгалт; бүх нөхцөлд 100% зөв танина гэсэн хэмжилт биш.

v2.4.0-ийн **51 автомат тест** тэнцсэн. Бодит 11.7 секундийн MP4-ийг бүтэн тоглуулж 71 кадр шалгасан; эргэлтийг зассаны дараа дугаарын бүртгэл хадгалсан. Туршилтын MP4-ээс бодит YOLO/OCR нь **1234УБА** уншсан. Бодит камер 0 дээр дүрс, гурван AI шалгалт, зогсоосны дараа дахин нээх үйлдэл тэнцсэн. Тайлан: `test_artifacts/media_verification_2_4.json`.

Бодит OCR нарийвчлалыг өөрийн тэмдэглэгээтэй Монгол test dataset дээр тусад нь үнэлнэ.
v2.3.0-ийн 39 автомат тест тэнцсэн. Санах ойн алдааны дараа камер/зураг дахин харагдах, шинэ кадргүй зураг дахин зурах, Tk зургийг давтан ашиглах, камер → зураг солихыг шалгасан.
Бодит GUI дээр камераас Windows-ийн жинхэнэ файл сонгох цонхоор зураг руу шилжүүлж, туршилтын `1234УБА` дугаарыг унших, хадгалах үйлдлийг шалгасан.
Мөн бодит камер дээр `MemoryError` зориуд үүсгэхэд дүрс сэргэж, дараа нь хэрэглэгчийн сонгосон Toyota зургийг `+ Зураг` товчоор оруулж `9638УЕН` гэж унших, хадгалах үйлдэл тэнцсэн.

```bat
.venv\Scripts\python.exe -m tools.verify_camera --index 0
.venv\Scripts\python.exe -m tools.verify_native_import --camera-first
.venv\Scripts\python.exe -m tools.verify_native_import --camera-first --simulate-render-failure --image "зургийн бүтэн зам.jpg"
```

Эдгээр бодит AI шалгалтыг санах ой хэмнэхийн тулд зэрэг ажиллуулахгүй.
OCR нь YOLO-ийн тайрсан хэсгийг EasyOCR `recognize()`-оор шууд уншдаг; давхар CRAFT/VGG текст илрүүлэгч ачаалахгүй.
Энэ нь анхны ачаалалтын 400+ MB түр давхаргын санах ойн алдааг арилгана. API тайлбар: [EasyOCR documentation](https://www.jaided.ai/easyocr/documentation/).

Хэрэв Windows `WinError 4551` гэж PyTorch DLL хоригловол `data/app.log`-ийг шалгана.
Энэ нь Windows Application Control-ийн хориг; админтайгаа тухайн албан dependency-г шалгуулна.
Python 3.13 CPU хувилбар дахин суулгах шаардлагатай үед [PyTorch-ийн албан зааварт](https://pytorch.org/get-started/previous-versions/) байгаа хос хувилбарын жишээ:

```bat
.venv\Scripts\python.exe -m pip install torch==2.9.1 torchvision==0.24.1 --index-url https://download.pytorch.org/whl/cpu
```
