# Бие даалтаа танилцуулах тайлбар

## 2–3 минутын танилцуулга

Миний бие даалтын сэдэв бол “PlateWatch — Автомашины улсын дугаар таних систем”. Зураг, видео болон камераас машины дугаар уншиж, танигдсан дугаарыг цаг, зураг, эх үүсвэртэй нь хадгалах зориулалттай Python desktop програм хийсэн.

Програмыг `run.bat` файлаар ажиллуулна. Энэ нь эхлээд Python орчин, шаардлагатай сангуудыг шалгаад `biydaalt.py` файлыг эхлүүлдэг. `biydaalt.py` нь програмын эхлэх цэг бөгөөд үндсэн цонхыг `platewatch/gui.py` доторх `PlateWatchApp` class үүсгэдэг.

Кодыг үүргээр нь салгасан. `gui.py` нь цонх, товч, түүх, тохиргоог хариуцна. `media.py` нь зураг, видео, камерын дүрсийг уншина. `worker.py` нь таних ажлыг арын thread дээр ажиллуулж, үр дүнг цонхонд буцааж өгдөг.

Таних үйл явц хоёр үндсэн шаттай. Эхлээд YOLO загвар зурган дотор дугаар хаана байгааг олно. Дараа нь тэр хэсгийг тайрч OCR загвараар тоо, үсгийг уншуулна. Энэ холбоос `recognition.py` дотор байрладаг. Кирилл PP-OCRv5 болон Монгол/Англи EasyOCR ашигласан. Хазайсан хоёр мөртэй дугаарыг `layout.py` дотор тоо, үсгийн бодит мөрөөр нь ялгаж тэгшилдэг.

OCR-оос гарсан текстийг `plates.py` шалгана. Үндсэн формат нь дөрвөн цифр, гурван кирилл үсэг. Видео болон камер дээр ижил машины дугаарыг өөр кадруудаар давтан баталж, нэг дугаарыг богино хугацаанд олон удаа хадгалахыг хязгаарласан. Хуваарийн төлөвийг `rules.py` тооцдог.

Мэдээллийг `storage.py` хадгална. Бүртгэлийн хүснэгт нь CSV, дэлгэрэнгүй мэдээлэл нь JSON, бүтэн кадр болон дугаарын хэсэг нь JPEG файл болно. Эдгээр нь `data` хавтаст байрладаг. Ингэснээр тусдаа SQL сервер шаардахгүй, бүртгэл бүрийг эх зурагтай нь шалгаж болдог.

Програмын ажиллагааг автомат тест болон бодит загвартай туршилтаар шалгасан. 109 автомат тест нь кодын ажиллагааг шалгана. Үүнээс тусдаа сүүлчийн туршилтаар 10 дугаарын зураг, 9 эсрэг жишээ, бодит видео, камер, CSV экспорт, тохиргоо хадгалалтыг шалгасан. Жишээ нь өмнө уншигдахгүй байсан `7960 УЕХ` дугаарыг эх зургийг импортлох болон гараар дахин шалгах хоёр үйлдлээр зөв уншсан.

Төсөл урьдчилан сургасан AI загвар ашигладаг. Бүх нөхцөлд 100 хувь зөв уншина гэж дүгнээгүй. Дараагийн хөгжүүлэлтэд Монголын тэмдэглэгээтэй том өгөгдлөөр загварыг сургаж, өөр машинуудтай тусдаа шалгалтын багц дээр нарийвчлал, хурдыг хэмжих боломжтой.

## Дэлгэц дээр үзүүлэх дараалал

1. `run.bat` ажиллуулж PlateWatch 2.8.1 цонхыг харуулна.
2. `+ Зураг` → дугаар тод харагдсан зураг сонгоно. Дугаар, тайралт, хуваарийн төлөвийг тайлбарлана.
3. `Илрэлтийн түүх` → танигдсан дугаараар хайж, нэг бүртгэл нээнэ. Бүтэн зураг, тайралт, мэдээллийг харуулна.
4. CSV экспорт хийж хадгалсан мөрийг харуулна.
5. `Хязгаарлалт` хэсэгт 4 цифр оруулаад өдөр/цагийн жишээ шалгана. Энэ нь тохируулсан хуваарийн тооцоо гэдгийг хэлнэ.
6. Код дээр `biydaalt.py → gui.py → worker.py → recognition.py → storage.py` дарааллаар гол хэсгүүдийг нээнэ.
7. Автомат тестийн команд болон бодит шалгалтын [тайланг](../test_artifacts/audit_2_8_1/final/report.json) харуулна.

Видео нь бодит хугацаанаасаа удаан шалгагдаж болно. Хамгаалалтад сонгосон богино бичлэгээ урьдчилан туршина. Загваруудыг анх татах үед интернэт хэрэгтэй; татсан загварууд дараа нь локал ажиллана.

## Багш асуувал

| Асуулт | Тайлбарлах хариулт |
| --- | --- |
| Яагаад YOLO ба OCR хоёуланг ашигласан бэ? | YOLO байршлыг, OCR бичгийг унших өөр өөр үүрэгтэй. |
| Програмын эхлэх код хаана вэ? | `biydaalt.py`-ийн `main()`. Цонхны код нь `platewatch/gui.py`. |
| AI загварыг өөрөө сургасан уу? | Одоогийн хувилбар урьдчилан сургасан YOLO/OCR ашигладаг. Холболт, боловсруулалт, формат, баталгаажуулалт, GUI, хадгалалт нь төслийн код. Өөрийн өгөгдлөөр сургах хэрэгсэл `tools/train.py` дотор бий. |
| Яагаад цонх гацахгүй ажиллах боломжтой вэ? | Хүнд таних ажлыг арын thread гүйцэтгэж, queue-ээр GUI-д үр дүн өгдөг. Дүрс харуулах ба AI шалгах ажил салсан. |
| 4 цифр + 3 үсэг шалгах нь юу гэсэн үг вэ? | `normalize_plate()` уншсан текст бүтэн форматтай эсэхийг шалгана. Дутуу тэмдэгтэд шинэ цифр, үсэг нэмэхгүй. |
| Ижил дугаар яагаад олон бүртгэгдэхгүй вэ? | `PlateTracker` кадруудаар уншилтыг батална; `TemporalGate` хадгалалтын хүлээлтийг тооцно. |
| Хязгаарлах өдрийг яаж олдог вэ? | Дөрвөн тооны сүүлийн цифрийг авч, `rules.py`-д өдөр/цаг, чөлөөлөх нөхцөлтэй харьцуулдаг. |
| Яагаад CSV, JSON ашигласан бэ? | Энэ хэмжээний локал төсөлд сервергүй хадгалалт, хүснэгтээр нээх, дэлгэрэнгүй мэдээлэлтэй тулгах боломж олгодог. |
| 109 тест гэдэг нь 109 зураг гэсэн үг үү? | Үгүй. Автомат кодын шалгалт 109. Бодит загвартай зургийн шалгалт тусдаа багцтай. |
| OCR 70% гэдэг нь 70% зөв гэсэн үг үү? | Загварын оноо. Бодит зөв таних хувийг тусдаа тэмдэглэгээтэй шалгалтын өгөгдлөөр хэмжинэ. |
| Импортын бүртгэлийн цаг нь зураг авсан цаг мөн үү? | Боловсруулсан цаг. Видеоны доторх байрлал `video_seconds`-д тусдаа хадгалагдана. |
| Гол хязгаар нь юу вэ? | Бүдэг, халхлагдсан, жижиг бичиг, өөр формат, орчны гэрэл/өнцөг. Бичлэгийн жижиг пикапын үсэг бүрэн батлагдаагүй хэвээр. |
