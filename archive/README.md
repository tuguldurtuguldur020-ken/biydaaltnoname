# Архивласан файлууд

Хавтас цэгцлэх үед өмнө үүссэн түр файлуудыг энд шилжүүлсэн.

- `temporary_tests/`: тестээс үлдсэн хоёр түр хавтас, тэдгээрийн файл.
- `generated/PlateWatch.spec`: өмнөх EXE build-ийн автоматаар үүссэн тохиргоо. Шинэ build-ийн spec нь `build/specs/` дотор үүснэ.
- `reorganization_manifest.json`: хуучин зам → шинэ замын жагсаалт. `tools`, `docs`, `configs` руу ангилсан файлуудын зам мөн орсон.

Архивын түр файл, хуучин spec нь програм эхлэхэд ашиглагдахгүй. Хэрэглэгчийн бүртгэл `data/`, өмнөх build `build/`, `dist/`, шалгалтын нотолгоо `test_artifacts/` дотороо бий.
